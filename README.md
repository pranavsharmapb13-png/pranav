# Pranav Sharma | Digital Marketer Portfolio

A modern, responsive single-page portfolio website for Pranav Sharma, built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## Preview locally

Open the project folder in a browser, or run a simple local server:

```bash
cd /workspaces/pranav
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages deployment

1. Push this project to a GitHub repository.
2. Open the repository in GitHub.
3. Go to Settings → Pages.
4. Under Source, select the branch and folder:
   - Branch: `main`
   - Folder: `/ (root)`
5. Save the settings.
6. GitHub will provide a live URL once the site is published.

Typical live URL format:

```text
https://<your-username>.github.io/<your-repository-name>/
```
