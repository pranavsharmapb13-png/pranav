# Pranav Sharma | Digital Growth Portfolio

Editorial, responsive portfolio for a digital marketer. Built with Next.js App Router, Tailwind CSS, and Framer Motion, with a static export for simple hosting.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Next.js exports the static site to `out/`.

## Publish

Deploy the contents of `out/` to any static host, including GitHub Pages. Configure the host to serve `out/index.html` as the site entry point.

## Before publishing

- Replace the clearly marked illustrative campaign figures and anonymized project examples with verified, approved case-study results.
- Confirm the contact email and professional profile links in `app/page.tsx`.
- Update the canonical domain in `app/layout.tsx`.

The original `index.html`, `style.css`, and `script.js` files remain available as the standalone static version.
